# Dados do Harpia Radar

`snapshot.json` é gerado todo dia por `bin/radar collect` e segue `schema/snapshot.schema.json`.
O histórico fica no próprio git: cada coleta é um commit.

Os dados deste diretório estão sob a licença [Creative Commons Atribuição 4.0 Internacional (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/deed.pt-br).
O texto completo está em [LICENSE](LICENSE). O código do projeto segue a licença MIT, na raiz do repositório.

O snapshot não contém nomes, logins nem e-mails de pessoas: só números agregados.
