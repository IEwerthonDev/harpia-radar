## Decisões fora da spec

- **README em dois idiomas.** A spec e as regras pedem README em português; a organização harpiafoss exige README em inglês. O `README.md` está em português e o `README.en.md` em inglês, com links cruzados. Ao migrar, decidir qual fica como principal.
- O CONTRIBUTING lista "o que ajuda a revisão" (código aberto, repositório público, uso no Brasil, alternativa a solução fechada) como orientação, não como critério obrigatório: a spec não define critérios de inclusão.
- O código de conduta aponta para o da comunidade Harpia, em vez de copiar o texto.
- Issues, post e avisos **não foram publicados**: são ações externas e a spec pede que os avisos sejam escritos à mão.
