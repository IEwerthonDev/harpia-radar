## Regras (na ordem em que são avaliadas)

**Atividade**

1. `archived` → Arquivado
2. último commit fora da janela (`window_days`) → Sem alterações recentes
3. último release nos últimos `release_max_age_months` meses → Ativo
4. senão → Ativo, sem release recente

**Sustentação**

1. `commits_90d` < `min_commits` → Poucos commits para medir
2. `top_author_share` > `max_top_author_share` ou `bus_factor` < `few_people_bus_factor` → Precisa de mãos
3. `bus_factor` ≥ `well_distributed_bus_factor` → Bem distribuído
4. senão → Poucas pessoas

## Decisões fora da spec

- "Commit nos últimos 90 dias" usa `last_commit_at` (qualquer commit, inclusive de bot), o mesmo dado que a página mostra em "Última alteração em". Os selos de sustentação usam só commits humanos.
- Fronteiras: commit exatamente há `window_days` dias conta como dentro da janela; release exatamente há 12 meses conta como recente.
- Projeto arquivado continua recebendo selo de sustentação.
