# Código de conduta

O Harpia Radar segue o código de conduta da comunidade Harpia:
https://github.com/harpiafoss/.github/blob/main/profile/README.md

Em resumo: respeito, gentileza e honestidade com todas as pessoas. Assédio, ataques, discriminação, doxing e exposição de dados pessoais não são tolerados. Isso vale também para como o Radar fala dos projetos e de quem os mantém.

Para relatar um problema, abra uma issue ou procure as pessoas listadas em [`.github/CODEOWNERS`](.github/CODEOWNERS).
